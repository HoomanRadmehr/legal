# MinIO presigned document flow

## Storage boundary

Django stores document metadata; MinIO stores bytes.
The bucket is private and object keys are generated by the backend.

## Initiate endpoint

```text
POST /api/v1/documents/uploads/
```

Input:

```json
{
  "matter_id": "uuid",
  "filename": "notice.pdf",
  "content_type": "application/pdf",
  "size": 1048576,
  "checksum": "optional-client-checksum"
}
```

The service:

1. Resolves the visible editable matter.
2. Enforces role and matter permission.
3. Validates extension, content type, size, organization quota if enabled, and active upload count.
4. Creates a random key such as `organizations/<org>/matters/<matter>/uploads/<upload-id>`.
5. Creates an `UploadSession` with expiry.
6. Returns short-lived presigned instructions.

Output includes the upload ID, method, URL, required headers or form fields, expiry, and polling URL.
The URL is never persisted in PostgreSQL.

## Client upload

The browser sends bytes directly to MinIO and displays local progress.
MinIO CORS allows only the frontend origin and required methods/headers.

## Completion endpoint

```text
POST /api/v1/documents/uploads/{upload_id}/complete/
Idempotency-Key: <uuid>
```

The service verifies:

- session belongs to the authenticated organization and requester or authorized manager;
- state permits completion;
- session has not expired;
- object exists at exactly the expected key;
- size matches expected size;
- content metadata is acceptable;
- checksum matches when a supported trustworthy checksum is available;
- no document already exists for a conflicting upload.

It marks the session `verifying` or `processing`, writes activity/outbox data, and schedules processing after commit.
Repeated valid completion with the same idempotency key returns the same result.

## Worker

A worker rechecks the object, performs the MVP validation hook, creates or updates `Document`, marks it `available` or `failed`, and publishes a user event through the outbox/realtime path.
No antivirus claim should be made unless a scanner is actually integrated.

## Download

```text
POST /api/v1/documents/{document_id}/download-url/
```

After permission and status checks, return a short-lived GET URL.
Audit the download request, not the URL itself.

## Cleanup

Celery Beat marks expired upload sessions and removes abandoned objects according to a simple safe policy.
Cleanup is idempotent and does not touch available documents.
